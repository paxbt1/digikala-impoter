# Digikala Importer (DKI)

افزونه‌ی **Digikala Importer (DKI)** برای وردپرس/ووکامرس است که امکان **جستجو** و **درج/به‌روزرسانی** محصولات از دیجی‌کالا را با استفاده از APIهای عمومی دیجی‌کالا فراهم می‌کند.

> این پروژه یک ابزار فنی برای انتقال داده است. مسئولیت رعایت قوانین، شرایط استفاده و حقوق معنوی محتوای دیجی‌کالا بر عهده‌ی استفاده‌کننده است.

---

## قابلیت‌ها

### 1) جستجو و درج از نتایج
- جستجو در دیجی‌کالا با API جستجو
- نمایش نتایج به همراه **تصویر محصول**
- درج/به‌روزرسانی محصول با یک کلیک
- امکان انتخاب **چند دسته‌بندی مقصد** در ووکامرس (نمایش درختی + چک‌باکس)

### 2) درج مستقیم با شناسه محصول
- دریافت `product_id` و درج/به‌روزرسانی همان محصول

### 3) درج از دسته‌بندی (صفحات برند/دسته دیجی‌کالا)
- وارد کردن لینک صفحه مثل:
  - `https://www.digikala.com/search/category-air-conditioner-2/uneva/`
- خواندن لیست محصولات و سپس **درج همه** (به صورت مرحله‌ای برای کاهش خطا/Timeout)

### 4) تشخیص ساده/متغیر
- اگر محصول دارای واریانت رنگ باشد، محصول به صورت **Variable** ساخته می‌شود.
- فقط یک ویژگی متغیر ایجاد می‌شود: **pa_color**
- برای هر رنگ، فقط **یک وارییشن** ساخته می‌شود (کمترین قیمت همان رنگ).
- کمترین قیمت بین رنگ‌ها به عنوان **پیش‌فرض انتخاب** قرار می‌گیرد.

### 5) تصاویر و گالری
- تصویر شاخص + گالری از تصاویر API دریافت و در مدیای وردپرس ذخیره می‌شوند.

### 6) قیمت ریال/تومان
- امکان تنظیم واحد قیمت:
  - خودکار (بر اساس واحد ووکامرس)
  - ریال (IRR)
  - تومان (تقسیم بر 10)

### 7) اعتباردهی (حقوق معنوی)
- در انتهای توضیحات محصول، لینک زیر اضافه می‌شود:
  - **«مشاهده در دیجی‌کالا»**
- در تنظیمات می‌توانید تعیین کنید لینک `nofollow` باشد (پیشنهادی).

## نصب

1. فایل ZIP افزونه را در مسیر زیر نصب کنید:
   - پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه
2. افزونه را فعال کنید.
3. ووکامرس باید نصب و فعال باشد.

---

## نحوه استفاده

### منوی افزونه
ووکامرس → **درج از دیجی‌کالا**

### تب «جستجو»
1. عبارت را وارد کنید و «جستجو» را بزنید.
2. دسته‌بندی(های) مقصد را در ستون سمت راست انتخاب کنید.
3. روی «درج» محصول موردنظر کلیک کنید.

### تب «درج با شناسه»
1. `product_id` را وارد کنید.
2. دسته‌بندی(های) مقصد را انتخاب کنید.
3. «درج/به‌روزرسانی» را بزنید.

### تب «درج از دسته‌بندی»
1. لینک صفحه برند/دسته را وارد کنید.
2. «خواندن محصولات» را بزنید.
3. دسته‌بندی(های) مقصد را انتخاب کنید.
4. «درج همه» را بزنید.

### تب «تنظیمات»
- واحد قیمت (ریال/تومان)
- حالت لینک اعتباردهی (nofollow/follow)

## نکات فنی و محدودیت‌ها
- دیجی‌کالا ممکن است **Rate Limit** اعمال کند؛ به همین دلیل درج گروهی به صورت مرحله‌ای و با تأخیر کوتاه انجام می‌شود.
- موجودی و وضعیت کالا بر اساس فیلدهای `status` و `availability` در API تشخیص داده می‌شود و ممکن است در برخی کالاها دقیق نباشد (وابسته به ساختار داده‌ی دیجی‌کالا).
- ویژگی‌های غیر از رنگ به صورت ویژگی‌های قابل‌نمایش در محصول ذخیره می‌شوند (برای جلوگیری از ایجاد بی‌رویه‌ی ویژگی‌های سراسری).

## رعایت حقوق معنوی دیجی‌کالا
این افزونه برای احترام به منبع داده:
- لینک «مشاهده در دیجی‌کالا» را در انتهای توضیحات درج می‌کند.
- پیشنهاد می‌شود حالت `nofollow` فعال باشد.
